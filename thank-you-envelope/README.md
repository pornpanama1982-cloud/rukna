# เว็บไซต์ซองจดหมายขอบคุณ 💌

เว็บไซต์ HTML, CSS และ JavaScript แบบไม่ใช้เพลง พร้อมแอนิเมชันซองจดหมาย หัวใจลอย และเอฟเฟกต์หัวใจเมื่อเปิดจดหมาย

## วิธีเปิดใน VS Code
1. แตกไฟล์ ZIP นี้ก่อน
2. เปิด VS Code
3. เลือก **File > Open Folder...** แล้วเลือกโฟลเดอร์ `thank-you-envelope`
4. เปิด `index.html` ในเบราว์เซอร์เพื่อใช้งาน

### แนะนำ
ติดตั้งส่วนขยาย **Live Server** ใน VS Code แล้วคลิกขวาที่ `index.html` > **Open with Live Server** เพื่อดูตัวอย่างและแก้ไขเว็บได้สะดวก

## แก้ข้อความในจดหมาย
เปิด `index.html` แล้วค้นหาบรรทัด `ขอบคุณน้าาา 💗` และแก้ข้อความตามต้องการ

## ไฟล์ในโปรเจกต์
- `index.html` — โครงสร้างหน้าเว็บ
- `style.css` — สี รูปทรง และแอนิเมชัน
- `script.js` — การเปิด/พับซองและเอฟเฟกต์หัวใจ

ฟอนต์จาก Google Fonts จะโหลดเมื่อมีอินเทอร์เน็ต หากออฟไลน์ เว็บยังใช้งานได้โดยใช้ฟอนต์สำรอง
